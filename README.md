# uzbek-search-engine

Full-text search engine tailored for the Uzbek language.

## Overview

A search engine designed with Uzbek morphology, Cyrillic/Latin script handling, and efficient ranking in mind.

## Goals

- Strong lexical retrieval for Uzbek text
- Support for both Latin and Cyrillic scripts
- Clean, extensible architecture
